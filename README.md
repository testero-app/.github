# Testero

Open source system for administering tests and assessments, designed
for educational settings: private schools, training organizations,
teachers, and trainers.

Testero replaces the manual cycle of paper → grading → transcription
with an integrated digital workflow.

## Projects

### 🌐 [testero-web](https://github.com/testero-app/testero-web)
Next.js frontend: the test-taking interface.

### ⚙️ [testero-backend](https://github.com/testero-app/testero-backend)
Spring Boot backend: API and business logic.

## Stack

- **Frontend**: Next.js, JavaScript
- **Backend**: Spring Boot, Java
- **Database**: PostgreSQL via Supabase
