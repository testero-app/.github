# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Testero, we ask that you
report it responsibly. Do **not** open public issues for security
matters.

### How to Report

Use GitHub's
[Private Vulnerability Reporting](https://github.com/testero-app)
feature, available on every Testero repository (Security tab →
Report a vulnerability).

Alternatively, email: `security@testero.app` *(coming soon)*

### What to Include

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested remediation (if any)

### Our Commitment

- We acknowledge receipt within 7 days
- We provide an estimated timeline for resolution
- We credit you in the advisory (if desired) once resolved

## Supported Versions

Testero is in active development. At this stage, only the latest
commit on `main` of each repository is supported.

## Out of Scope

- Vulnerabilities in third-party dependencies (report upstream)
- Social engineering, physical attacks, denial of service

Thank you for helping keep Testero secure.
